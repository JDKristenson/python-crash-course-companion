## Try It Yourself Exercises

### 1-1: python.org
Explore the Python home page to find topics that interest you. As you become familiar with Python, different parts of the site will be more useful to you.

### 1-2: Hello World Typos
Open the hello_world.py file you just created. Make a typo somewhere in the line and run the program again. Can you make a typo that generates an error? Can you make sense of the error message? Can you make a typo that doesn't generate an error? Why do you think it didn't generate an error?

### 1-3: Infinite Skills
If you had infinite programming skills, what would you build? You're about to learn to program. If you have an end goal in mind, you'll have an immediate use for your new skills; now is a great time to write brief descriptions of what you want to create.

## Quick Reference

### Running Python
```python
# In terminal/command prompt:
python
# or
python3

# To run a Python file:
python filename.py
# or
python3 filename.py
```

### Your First Program
```python
print("Hello Python world!")
```

## Troubleshooting Tips
- If Python isn't recognized, check your PATH environment variable
- Make sure you're using Python 3 (not Python 2)
- On Mac/Linux, you might need to use `python3` instead of `python`
- Check Python version: `python --version` or `python3 --version`
