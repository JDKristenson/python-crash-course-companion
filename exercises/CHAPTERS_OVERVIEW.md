# Python Crash Course - Chapter Index

Companion topic index for _Python Crash Course, Third Edition_ by Eric Matthes. Only chapters 1 and 2 currently have dedicated guides here. Later topics are a learning roadmap, not completed guides or implemented projects.

## Part I: Basics

### Chapter 1: Getting Started
**Focus:** Installation, running Python, first program  
**Exercise Guide:** `chapter_01_getting_started.md`

### Chapter 2: Variables and Simple Data Types
**Focus:** Strings, numbers, comments  
**Exercise Guide:** `chapter_02_variables_and_data_types.md`

### Chapter 3: Introducing Lists
**Focus:** Creating lists, accessing elements, modifying lists  
**Key Skills:** Indexing, slicing, append(), insert(), remove(), pop(), sort()

### Chapter 4: Working with Lists
**Focus:** Looping through lists, numerical lists, list comprehensions  
**Key Skills:** for loops, range(), min(), max(), sum(), slicing

### Chapter 5: if Statements
**Focus:** Conditional tests, if-elif-else chains, checking lists  
**Key Skills:** Comparison operators, boolean expressions, checking for values

### Chapter 6: Dictionaries
**Focus:** Key-value pairs, accessing values, looping through dictionaries  
**Key Skills:** get(), keys(), values(), items(), nesting

### Chapter 7: User Input and while Loops
**Focus:** Getting input, while loops, controlling loop flow  
**Key Skills:** input(), int(), break, continue, removing list items

### Chapter 8: Functions
**Focus:** Defining functions, parameters, return values  
**Key Skills:** Default values, keyword arguments, arbitrary arguments, modules

### Chapter 9: Classes
**Focus:** Object-oriented programming, creating classes, inheritance  
**Key Skills:** __init__(), methods, attributes, inheritance, importing classes

### Chapter 10: Files and Exceptions
**Focus:** Reading/writing files, error handling  
**Key Skills:** open(), read(), write(), with statements, try-except blocks

### Chapter 11: Testing Your Code
**Focus:** Unit tests, test cases  
**Key Skills:** pytest, test functions, fixtures, test classes

## Working Through the Book
1. Read the chapter in the book
2. Open an existing guide where available
3. Create your own local exercise directory under `my_work/` (not currently tracked)
4. Consult book resources only after independently obtaining and verifying them; the `book_resources` gitlink has no tracked upstream URL
5. Use the quick reference guides for syntax help
